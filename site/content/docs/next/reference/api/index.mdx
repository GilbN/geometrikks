This reference is generated from the OpenAPI schema the app serves at `/schema`. Each operation has its own page in the sidebar, grouped by tag.

Scripts send an API key as a bearer header. [API keys](../../features/authentication/api-keys.mdx) covers creating one and what each scope may do. The [API guides](../api-guides/polling.mdx) walk through polling for recent records, the [WebSocket messages](../api-guides/websockets.mdx) and the [abuse report redaction](../api-guides/abuse-report-redaction.mdx) rules. The [endpoint notes](../api-guides/endpoint-notes.mdx) explain what the CrowdSec map data, the integration summary and source activity report, and which endpoints take `window`.

Examples on the operation pages use `https://geometrikks.example.com` as the server. Put the URL of your own instance in its place.
